단계확인할 결과통과 기준

다시 실행하기

uv run --extra recovery python -m kv_cache_agent.validation --with-tests
# API 키를 수정한 뒤 소규모 연결과 실제 Schema만 확인
uv run --extra recovery python -m kv_cache_agent.validation --live-smoke

실제 연구 검증은 위 API 확인 후 기존 CLI의 --mock 옵션을 제거해 수행하고, 논문 페이지와 웹 원문을 직접 대조합니다.

실행 시나리오

예상한 실패와 종료도 올바르게 동작하면 검증 PASS원본 JSON 다운로드

SCENARIOS

State의 최소 구조화 결과와 부모 체크포인트, 외부 이벤트를 읽은 화면입니다. 전체 Prompt, 전체 LLM Response와 검색 원문을 추가로 저장하지 않습니다.
