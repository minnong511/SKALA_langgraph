# 프로젝트 문서 및 검증 안내

기술 설명, 오류 수정 이력, 단계별 테스트 기록을 한곳에서 관리합니다.

| 위치 | 내용 | 시작 문서 |
|---|---|---|
| 기술문서/ | 디렉토리 구조, 인터페이스, 실행 흐름, 구현 상태 | [구조](기술문서/directory_structure.md), [흐름](기술문서/workflow.md), [구현 현황](기술문서/implementation.md) |
| 디버깅/ | 오류 원인, 수정 내용, 재검증 이력 | [오류 추적표](디버깅/ISSUES.md) |
| 테스트/ | 단계별 검증 기준과 실행 명령 | [단계별 검증표](테스트/단계별검증.md) |
| 테스트/실행결과/ | API 점검 JSON, 자동 테스트 결과, 데모 검증 요약 | [실행결과 폴더](테스트/실행결과/) |

실행 가능한 자동 테스트 코드는 루트의 `tests/`에 유지합니다.
수동 API 점검 코드는 `scripts/api_smoke.py`에 있으며 다음 명령으로 실행합니다.

```bash
python scripts/api_smoke.py
```

이 명령은 실제 API를 호출하며, 결과는 `검증문서/테스트/실행결과/`에 저장합니다.
전체 프로젝트 실행의 원본 산출물은 기존 `outputs/{run_id}/`에 저장합니다.
API 키와 `.env` 원문은 문서나 결과 파일에 기록하지 않습니다.
